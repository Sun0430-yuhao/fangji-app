# 立项纪要

- **问题**：方剂学 19 章 175 首方剂体量大、易遗忘、无法量化掌握度；把桌面《方剂学（表格汇总）》静态表格变成移动端"学—记—测—复"闭环学习工具。
- **本轮做**：本地离线 MVP——方剂库浏览与关键词检索、方剂详情、背诵卡片（间隔重复）、自测刷题与错题本、进度统计与打卡；移动版 Web（PWA）。
- **本轮不做**：App 打包（阶段 2 另行确认）、云同步/账号、知识图谱、真题库、AI 问答、方歌朗读、易混对比辨析、iOS 验证。
- **体验一句**：打开 App 第一眼就知道今天该复习哪几方，3 分钟背完一组卡片，当场看到今日进度涨了一格。
- **成功标准（可勾选）**：
  1. 从首页"今日任务"进入，不看任何说明完成一组 ≥10 张卡片背诵，结束后当前屏看到今日进度变化。失败样子：背完没有任何反馈，不知道做完了没有。
  2. 章节列表 → 任一方剂详情，组成（君臣佐使）/功用/主治/歌诀同屏可读，点"加入背诵"后该方进入背诵队列。失败样子：字段错位、缺块、按钮点了无反应。
  3. 刷题答错后，"我的 → 错题本"出现该题并可当场重做。失败样子：答错后找不到错题在哪。
  4. 搜索"麻黄"能列出麻黄汤及相关方剂。失败样子：搜索无结果或报undefined。
  5. **负面**：`formulas.json` 缺失/损坏时，App 显示人话错误页（说明原因 + 重试按钮），不白屏、不卡死。
- **兼容矩阵**：单一变体（移动端 Web/PWA）。验收入口：Android 手机浏览器 + 桌面浏览器（开发调试），两处都要走主路径；iOS 为 Blocked 环境项。
- **界面**：有。产品出设计说明（见 `02-PRD与设计说明.md`），沿用阶段 0 已确认的新中式风格与 5 屏效果图（`mockups/`）。
- **风险与依赖**：
  1. docx 个别方剂字段跨行/缺失（如正柴胡饮用法断行）→ 解析脚本容错 + 抽样人工校对 20 方；
  2. 用户真机为 Android，iOS/Safari 验证记 Blocked；
  3. 间隔重复算法本轮为简化三档（当日/明天/序列延长），字段按 SM-2 预留，二期升级。
- **角色**：项目经理、产品经理、研发、测试（虚拟项目组）。
- **例外**：无。
- **讨论中被驳回的点**：
  1. 照搬《方剂通》方案的"后端 API + PostgreSQL + 云同步"架构——单人离线工具，过度设计，二期再议；
  2. 墨绿主色——沿用已确认的朱砂宣纸设计稿；
  3. 五段式导航——首页已承载每日任务，四 Tab（学习/背诵/刷题/我的）够用；
  4. AI 问答、知识图谱、真题库——三期候选，不进本轮。
