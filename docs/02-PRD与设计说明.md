# PRD 与界面设计说明（方剂学学习平台 MVP）

## PRD

- **功能名**：方剂学移动端学习平台 MVP（学—记—测—复闭环）
- **需求描述**：为中医学生/备考者解决"方剂多记不住、复习无节奏、掌握度不可见"的问题。
- **非目标**：App 打包、云同步、账号、真题库、知识图谱、AI 问答、朗读、易混对比、iOS 适配验证。
- **数据来源**：桌面《方剂学（表格汇总）》docx → 一次性解析为 `formulas.json`（19 章 / 175 方）。

### 页面（入口、层级、视线内结果）

| 页面 | 入口 | 这一页必须让人看见什么 | 视线内结果 |
|---|---|---|---|
| 首页 | App 打开默认页 | **第一眼是"今日任务"卡**（待复习 X / 新学 Y，一个"开始"按钮）；其下连续打卡天数、每日歌诀、章节进度网格 | 点"开始"直接进卡片，不需再找入口 |
| 章节列表 | 首页章节网格 / "全部 19 章" | 章名、方数、进度条 | 点章进方剂列表 |
| 方剂详情 | 方剂列表 / 搜索 | 方名+出处、君臣佐使组成表（四色角色标签）、功用、主治、歌诀、注意；底部"加入背诵"主按钮 + 收藏 | 点"加入背诵"按钮变为"已加入"，当前屏可见 |
| 背诵卡片 | 首页今日任务 / Tab"背诵" | 大字翻面卡（歌诀填空或方名→组成）、进度"3/16"、翻面后三档自评：忘记(红)/模糊(黄)/记得(绿) | 自评后立刻出下一张；一组结束出"下一句" |
| 刷题 | Tab"刷题" | 题型标签、题干、四选项、答后即时对错反馈与一句解析 | 答错当下看到"已收入错题本" |
| 我的 | Tab"我的" | 总进度环、已学/收藏/错题三数、章节掌握度、错题本与收藏入口 | 错题本内可当场重做并移除 |

### 用户旅程（覆盖 U1～U5）

1. 打开 App → 首页今日任务"开始" → 逐张翻面自评 → 完成页看到"今日已完成，明日 X 张待复习"。
2. 首页章节网格 → 解表剂 → 麻黄汤详情 → 加入背诵 → 按钮变"已加入"。
3. Tab 刷题 → 答题 → 答错 → 我的 → 错题本 → 重做 → 移除。
4. 首页搜索框输入"麻黄" → 结果列表 → 进详情。

### 用户故事（含负面）

- 作为第一次使用的学生，我打开 App 不看任何说明，能靠页面文字完成一组背诵并看到进度。
- **负面**：数据文件缺失时，我看到"方剂数据没有加载成功，请检查数据文件后重试"和重试按钮，而不是白屏。

### 实现逻辑（业务规则）

- **记忆调度（简化 SM-2）**：每卡字段 `rep / interval / due / strength`。自评"忘记"→ 当日重来；"模糊"→ 明天；"记得"→ 间隔按 1→2→4→7→15→30 天逐级延长。到期卡片自动并入今日任务。
- **自动出题**：从 175 方随机取题干（方名→君药 / 组成→方名 / 功用→方名 / 主治→方名 / 歌诀填空），干扰项同章优先。
- **进度**：某方"已学"= 完成过详情浏览或卡片自评；章进度 = 已学/总方数。
- **输入/输出/边界**：无用户文本输入（除搜索）；搜索空结果 → "没有找到相关方剂，换个关键词试试"；localStorage 损坏 → 重置并提示"学习记录已重置"。

### 兼容矩阵

单一变体：移动 Web/PWA。验收真机 Android 浏览器 + 桌面浏览器（开发调试）。

### 验收（可勾选，含负面）

见立项纪要成功标准 1～5；另加：

6. 冷启动（清站点数据后再进）：首页正常渲染，进度归零但页面可正常使用。
7. 连续答错 3 题后，错题本显示 3 题且可逐题重做。

## 界面设计说明（研发照做，测试抽检）

- **风格**：新中式本草风。令牌：`--paper #f4eee1`、`--card #faf6ea`、`--ink #2b2620`、`--ink-light #7d7466`、`--cinnabar #b03a2e`、`--amber #c08a2d`、`--bamboo #5f7050`；衬线宋体（Noto Serif SC / 宋体兜底）。参照 `mockups/` 5 屏效果图 1:1 还原。
- **主路径最多 3 步**：首页 →（点开始）→ 卡片 → 完成页。
- **第一眼**：今日任务卡（朱砂主按钮"开始背诵"）；章节网格在其下，不抢视线。
- **每屏的下一句**：
  - 背诵完成页："今日已完成 ✅ 明日预计 X 张待复习。去刷题巩固 →"
  - 空错题本："暂无错题，刷题后答错的题会自动收到这里"
  - 搜索空结果："没有找到相关方剂，换个关键词试试"
  - 数据加载失败："方剂数据没有加载成功，请检查数据文件后重试"＋重试按钮
- **禁止出现的词**：任何其他产品/项目名（如"方剂通"）、占位数字（如"123 方"这类假数据）、内部字段名（rep、due 等不出现在界面上）。
- **美观要/不要**：要纸感、印章红点缀、圆角卡片、克制的阴影；不要渐变堆叠、不要宣传页式大图、不要多于 4 个底部 Tab。
- **UI 六条对照**：每页标题说清"这是什么页面"；按钮贴着它作用的对象（加入背诵在详情页底部）；主区域无大块空白；推荐动作唯一朱砂色；加载/空/失败/成功四态都有文案；无误导文案与假数字。
