# 迭代记录

## 第1轮（方案 v1 → v2）发现 / 改动

- 【测试】发现：必测项缺"清缓存冷启动"与"坏数据"两条，只测正常路径一定会漏 → 签收清单加冷启动行、负面行（删 formulas.json 打开 App）。
- 【研发】发现：v1 方案默认 docx 字段整齐，实际存在跨行断行（正柴胡饮），直接解析会错位 → 数据管线加容错 + 缺字段清单 + 抽样人工校对 20 方。
- 【产品】发现：v1 首页第一眼是章节进度网格，第一次使用者不知道先点哪 → 首页信息架构调整：今日任务卡置顶，章节网格下沉。
- 改动落盘：`02-PRD与设计说明.md` 首页行、验收 6/7；`03-技术方案.md` 数据管线容错段。

## 第2轮（方案 v2 → v3）发现 / 改动

- 【产品】发现：背诵完最后一张没有"下一句"，用户会停在空白 → 完成页固定文案"今日已完成，明日预计 X 张待复习。去刷题巩固 →"。
- 【测试】发现：v2 验收入口只写"浏览器"，实际会只测桌面 → 验收改双入口（Android 真机 + 桌面），iOS 显式记 Blocked。
- 【研发】发现：完整 SM-2（0~5 分评分）本轮过重 → 简化三档但保留 rep/interval/due/strength 字段，二期无损升级；写入方案"禁止照搬"段。
- 【项目经理】冻结范围：易混对比、方歌朗读、打卡日历热力图移出本轮，防止第 3 轮被新需求挤掉。
- 改动落盘：`02-PRD与设计说明.md` 下一句段、兼容矩阵；`03-技术方案.md` 记忆调度段；`01-立项纪要.md` 本轮不做。

## 第3轮（实现后）发现 / 改动 / 复验

- 【研发】发现（视线）：背完今日任务回首页，任务卡仍显示"10 今日新学 + 开始背诵"，不说"已完成"——状态不说话。改动：首页任务卡完成态（✓ 今日任务已完成 / 明日预计 X 张 / 去刷题巩固 →）。
- 【研发】发现（防呆）：`buildDeck` 每次进入背诵页都塞 10 张新卡，无每日上限，完成后可无限新学。改动：`store.todayNew` 持久化计数，新卡按剩余额度补充；再进背诵显示"今日没有待复习的卡片"。
- 【研发】发现（坏路径）：自审中数据文件经 SW 预缓存吞掉（负面包成 HTML 回退页），重试永失败。改动：`formulas.json` 移出预缓存，改 NetworkFirst 运行时缓存；复验：删文件→错误页→恢复→点重试→首页恢复。
- 【研发】顺手修复：牌组构建返回到期复习卡时对象/ID 混用导致复习卡被过滤（原 deck 只有新卡）。改动：统一返回 ID。
- 复验（新构建、清 SW/缓存/记录）：完成 10 张 → 首页完成态 ✓；todayNew 持久化 count=10 ✓；再进背诵空牌组文案 ✓；断网重载 19 章可渲染 ✓；手机尺寸截图对照 UI 六条无命中 ✓（`docs/截图-首页完成态.png`）。
- 邻域回归：首页任务态（未完成）显示不变；背诵翻面/自评/完成页下一句复走正常；错题本空态文案不变。

## 第4轮（用户反馈小迭代：进度重置 + 刷题直进）

- 【用户】反馈：进度要能重置，每部分都要能；刷题要能直接下一题。
- 【产品】定标：重置必须二次确认 + 当前屏数值归零；答对 1s/答错 1.5s 自动进题，保留手动"下一题"。
- 【研发】改动：store 加 6 个重置动作（记忆/进度/错题/收藏/打卡/全部）；我的页加"数据管理"分区（vant 确认弹窗，取消不变）；QuizView 答完定时自动进题，手动点击清定时器防双跳。
- 【测试】复验：取消重置数据不变 ✓、确认后归零且当前屏同步 ✓、刷题答错后无操作自动跳到第 2 题 ✓；构建后旧 SW 提供过期 chunk 导致动态导入 404，清 SW 后恢复（再次印证缓存层纪律）。
- 签收：见 `08-测试签收-第4轮.md`。

## 第5轮（刷题改回手动 + 小优化包）

- 【用户】反馈：选对选错都不要自动进下一题，要点击进入；选对也要有解析；小优化包一起做。
- 【研发】改动：
  1. QuizView 去掉自动跳题；对错均出「解析」区块（标题+正文），等点「下一题」。
  2. 每日歌诀只在有歌诀的方里轮转。
  3. 搜索支持拼音全拼/首字母（pinyin-pro），占位提示改为「麻黄 或 mht」。
  4. 校对修正表：香酥散→香苏散、当归拈痛汤括号闭合；清单见 `校对清单.md`。
  5. PWA 图标改为圆角印章风（宣纸底+朱砂方印）。
- 【测试】复验：mht→麻黄汤；xiangsu→香苏散；答错/答对后 1.6s 仍停在当前题且有解析章；点下一题才前进。

## 第6轮（去10张硬顶 + 刷题上一题）

- 【用户】反馈：重置/清空每次都能做且不限次数；不要每日十次卡；刷题要有上一题；开会研究更多优化点。
- 【研发】去掉 `newPerDay/todayNew`；`buildDeck` 本轮 30 新方+全部到期，可无限「再学一组」；首页「还可学」；Quiz 历史栈 + 上一题/下一题。
- 【产品】候选清单见 `09-第6轮-立项与优化清单.md`（章节刷题、张数可选、填空卡、手势等）。
- 【测试】见构建后复验。

## 第7轮（灵活度：张数自选 + 按章练 + 双端工程）

- 【用户】要操作更灵活、体验优先；高优先级两项都做；要出 Android + iOS。
- 【研发】首页本轮张数 10/30/50/全部；章节页「背本章/测本章」；刷题顶栏可切换章节范围；Capacitor 接入并生成 `android/` + `ios/`；本机无 SDK 不能出 APK，说明见 `10-双端打包说明.md`。
- 【产品】体验一句：随时改张数、随时只练一章、前后翻题不卡手。
