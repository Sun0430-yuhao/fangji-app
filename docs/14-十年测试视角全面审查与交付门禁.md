## 2. 缺陷清单（按严重度）

### P0 — 阻断交付（必须修或真机证伪）

#### P0-1 冷启动「方剂载入中」死锁（回归风险）

| 项 | 内容 |
|----|------|
| 现象 | 旧包长期停在载入页，无法进首页 |
| 根因 | Capacitor WebView + PWA SW `NetworkFirst` 拉 `formulas.json` 挂起；且无硬超时 |
| 代码状态 | **已改**：内置 JSON、`sw-guard`、`build:cap` 自毁 SW、15s 超时 |
| 残留风险 | `index.html` 仍注入 `registerSW.js`，与 `guardServiceWorker` 存在**竞态**（SW 可能在 guard 之后又注册再自毁） |
| 关闭条件 | **卸载旧包**后装新包；冷启动 ≤5s 进首页；断网冷启动亦可进；连续杀进程重开 3 次稳定 |
| 真机结果 | ☐ 未测（交付前必测） |

#### P0-2 启动闪屏图标压扁/丑陋

| 项 | 内容 |
|----|------|
| 现象 | 约 1s 闪屏中吉祥物被拉扁，「方剂学」旁图标变形 |
| 根因 | `Theme.SplashScreen` + 整图 `@drawable/splash` 作 `android:background` |
| 代码状态 | **已改**：纯色 `splash_background` + 正方形 `splash_icon` |
| 关闭条件 | 真机冷启动目视：图标不拉伸、比例正常、无异常播放钮/遮罩观感 |
| 真机结果 | ☐ 未测 |

#### P0-3 安卓「导出学习进度」很可能无效

| 项 | 内容 |
|----|------|
| 位置 | `ProfileView.vue` → `Blob` + `<a download>` |
| 风险 | Capacitor/系统 WebView 常**忽略 download** 或无法落到「下载」目录；用户以为已备份，卸载后进度全丢 |
| 使用场景 | 换机、重装、清数据前 — 恰是备份最关键时刻 |
| 建议修法 | Capacitor Filesystem / Share 插件分享 JSON；或展示可复制文本 + 明确「请粘贴保存」 |
| 关闭条件 | 真机导出后能分享到微信/文件夹或剪贴板保存成功，再清空数据后导入恢复 |
| 状态 | **代码已修**（`backup-io`：分享 → 剪贴板 → download）；☐ 真机未测 |

#### P0-4 错题本答对移出后，列表索引错位

| 项 | 内容 |
|----|------|
| 位置 | `WrongView.vue`：`redone[wi]` 用**数组下标**；`removeWrong` 后下标左移 |
| 复现 | 错题 ≥2：先对第 0 题答对（0.8s 后删除）→ 原第 1 题变成第 0；若第 1 题曾点错过，`redone` 状态可能套到别的题上，出现「没点就显示对/错」或无法再点 |
| 建议 | 用稳定键（`fid+ts` 或错题唯一 id），删除按 id，勿按下标缓存 UI 态 |
| 状态 | **代码已修**（`uid` + `wrongKey`）；☐ 真机多题连做未测 |

#### P0-5 小章节刷题：选项不足 / 空题组体验坏

| 项 | 内容 |
|----|------|
| 数据 | 驱虫剂 2 方、君药种类 1；涌吐剂 3 方、君药种类 1；安神剂 3 方、君药种类 3 |
| 位置 | `QuizView.buildQuestions`：`sample(allHerbs, 3, …)` 不足 3 时选项可能 &lt;4；章内方太少时干扰项重复或题量怪异 |
| 空组 | `flat` 为空时 `questions=[]`，界面停在「题目生成中…」**永久假加载**（无失败态） |
| 使用 | 用户点「测本章」进驱虫/涌吐等小节，易遇到怪题或空转 |
| 建议 | 选项不足时跨章补干扰项；`qs.length===0` 显示空态+返回，禁止「生成中」死等 |
| 状态 | **代码已修**（`samplePad`/`buildOptions` + 空态文案）；☐ 真机测本章未测 |

## 3. 模块审查纪要

### 3.1 启动与壳

- `main.js` 先 `guardServiceWorker` 再挂载：方向正确。  
- `App.vue` 超时与错误页：方向正确；**真机未证**。  
- Android `styles.xml` 闪屏：方向正确；**真机未证**。  
- 旧 APK 残留 SW：必须**卸载或清存储**，覆盖安装不足以当关闭条件。

### 3.2 数据层

- 221 方，id 无重复，无缺 id；功用全覆盖。  
- 内置 import 消除 fetch 死锁类故障，利于离线。  
- 拼音索引同步 CPU：桌面约数百 ms 量级，真机低端需观察是否触发慢提示。

### 3.3 学习 / 背诵

- 牌组 = 到期 + 新学；忘记重插逻辑整体合理。  
- 三卡型轮换有回退，避免挖空失败卡死。  
- 风险见 P1-2、P1-4。

### 3.4 刷题 / 错题

- 对错计数与「首次作答才计入」合理。  
- 小章干扰项不足、空题组假加载：P0-5。  
- 错题索引：P0-4。

### 3.5 我的 / 备份

- 重置均有确认，正面。  
- 导出实现不适应安卓：P0-3。  
- 「覆盖安装一般不丢；卸载清空」文案正确，但若导出失败则用户无退路。

### 3.6 自动化门禁现状

`npm run qa` 已含「交付阻断门禁」源码断言（内置数据、SW guard、闪屏主题、硬超时等），**仍缺**：

- 仪器化/真机冷启动  
- 导出文件落地断言  
- 错题删除后的 UI 态  
- 小章刷题选项数 ≥4  

故：**qa 全绿 ≠ 可交付**。
