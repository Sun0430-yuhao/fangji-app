# 交付阻断缺陷与流程修正

**日期**：2026-11-11  
**级别**：阻断（不得交付）

## 现象

1. 冷启动约 1 秒闪屏：吉祥物被拉扁、观感差（「方剂学」旁图标变形）。
2. 随后长期停在「方剂载入中…」，无法进入首页。

## 根因

| # | 根因 | 说明 |
|---|------|------|
| A | Capacitor WebView + PWA Service Worker | `vite-plugin-pwa` 对 `data/*.json` 使用 `NetworkFirst`；SW 内 `fetch` 绕过 WebView 本地资产拦截，请求挂起 → 前端 `ready` 永不置真 |
| B | 数据靠相对路径 `fetch('data/formulas.json')` | 与 A 叠加后无超时、无内置兜底，表现为永久转圈（错误页也不出） |
| C | `Theme.SplashScreen` + `android:background=@drawable/splash` | Android 12+ 闪屏 API 下整图背景/图标槽位拉伸，方形素材被压扁 |

## 为何「测试说可交付」仍漏过

上一轮 `qa_smoke.mjs` + 验收报告主要覆盖：

- 源码关键字 / 逻辑单测（目标、挖空、备份）
- `vite build` 成功

**未覆盖（流程漏洞）**：

1. **真机/模拟器冷启动**：杀进程 → 打开 → 必须 5 秒内进首页  
2. **原生包内 SW 行为**：APK 资产里是否注册会拦截本地 JSON 的 Worker  
3. **闪屏主题资源约束**：是否误用整屏图当 `android:background`  
4. **加载负面路径**：超时必须出错误页，禁止无限「载入中」

结论：自动化 34/34 **不能**等价于「可交付」；缺少 **安装包冒烟阻断项**。

## 已做修复

1. `src/data.js`：打包内置 `formulas.json`，不再运行时 fetch  
2. `src/sw-guard.js` + `main.js`：原生环境注销 SW 并清 Cache  
3. `vite build --mode capacitor`：`selfDestroying` SW，APK 构建走 `build:cap`  
4. `App.vue`：15s 硬超时 → 错误页；载入页用正方形 `boot-icon`  
5. `styles.xml`：纯色 `splash_background` + `@drawable/splash_icon`  
6. `qa_smoke.mjs`：新增「交付阻断门禁」一组；失败则 exit 1
