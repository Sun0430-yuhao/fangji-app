# 方剂学 · Android / iOS 打包说明

本仓库已接入 **Capacitor**，原生工程目录：

- `android/` —— Android Studio 工程（本机已生成）
- `ios/` —— Xcode 工程（本机已生成；**正式编译与上架必须在 Mac 上完成**）

应用 ID：`com.fangji.study`　应用名：方剂学

---

## 共用前置

```bash
cd fangji-app
npm install
npm run build
npx cap sync
```

每次改前端后都要再跑一遍 `npm run build && npx cap sync`，再打开原生工程打包。

## Android（APK / AAB）

### 环境

1. 安装 [Android Studio](https://developer.android.com/studio)
2. SDK Manager 勾选：Android SDK、Android SDK Build-Tools、一个较新的 API（建议 34+）
3. 确认能识别 `java`（Android Studio 自带 JBR 即可）

### 用 Android Studio 出包（推荐）

```bash
npm run build
npx cap sync android
npx cap open android
```

在 Android Studio：

1. 等 Gradle Sync 完成
2. **Debug 安装到手机**：点 Run ▶（需开 USB 调试）
3. **正式 APK**：`Build` → `Build Bundle(s) / APK(s)` → `Build APK(s)`  
   产物一般在：`android/app/build/outputs/apk/`
4. **上架用 AAB**：`Build` → `Generate Signed Bundle / APK` → 选 Android App Bundle，按向导创建/使用密钥库

### 命令行（装好 SDK 后）

```bash
cd android
.\gradlew.bat assembleDebug
# 产物：android/app/build/outputs/apk/debug/app-debug.apk
```

> 当前这台开发机未检测到 Android SDK / Java，所以 **APK 需在你本机装好 Android Studio 后生成**。工程与同步脚本已就绪。

## iOS（需 macOS + Xcode）

Windows 上可以生成/维护 `ios/` 工程文件，但：

- **不能在 Windows 上编译出可安装的 IPA**
- 真机调试、Archive、上架 App Store 都必须在 **Mac + Xcode** 完成

### 在 Mac 上

1. 把整个 `fangji-app` 拷到 Mac（或 git clone）
2. `npm install && npm run build && npx cap sync ios`
3. `npx cap open ios`（用 Xcode 打开）
4. 选择开发团队（Signing & Capabilities）
5. 真机 Run，或 `Product` → `Archive` 上传 App Store Connect / 导出 IPA

CocoaPods（若提示需要）：

```bash
cd ios/App
pod install
```
